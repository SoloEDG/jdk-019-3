# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 沿路径文字

选中任意路径后，在右侧属性面板「PATH TEXT」中**添加路径文字**，可编辑内容、字体、字号、字距、起始偏移与方向（正向/反向）。

- 字符按**实际曲线弧长**定位，增删控制点不会导致字形突然堆叠；拖动节点改形路径时排版实时跟随。
- **组缩放**（属性面板 TRANSFORM）会等比缩放路径与文字度量；单独改**字号**则让文字沿原路径重新排布，二者结果不同。
- 文字超出路径长度时，溢出字符以红色标出并绘制溢出范围，字号不会被悄悄缩小。
- **转为字形轮廓**：文字烘焙为路径（保留字符洞口与颜色），不可再编辑；`Ctrl/Cmd+Z` 或 ↶ 撤销可恢复原文与路径关联。
- **导出 SVG** 时可选：保留可编辑文字（`<textPath>`，文件小但依赖查看端字体）或转为字形轮廓（`<path>`，无需字体但文件更大），对话框会显示两种方式的体积预估与差异说明。

## 校验

- `npm run typecheck`：类型检查。
- `node --experimental-strip-types scripts/sanity.ts`：排版引擎纯逻辑自检（弧长定位、控制点细分稳定性、溢出、方向）。
- `node scripts/smoke.mjs`：端到端冒烟测试（需可用的 Chromium）。
